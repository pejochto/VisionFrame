Frequently asked questions

Why does Windows show a warning when I start the installation?

Windows SmartScreen shows a “Windows protected your PC” message for any program that is not signed with a paid code-signing certificate. Those certificates cost several hundred dollars a year, and passing that cost on would mean a higher price or a subscription. I would rather keep SonarDepthPro a single, affordable one-time purchase.

The warning does not mean the file is unsafe. It only means the publisher has not paid to be pre-verified. To continue, click More info and then Run anyway. Only ever install the file you downloaded from the link in your purchase or trial email, and if anything looks wrong, email support@visionframe.se before you run it.

Windows 11: “Smart App Control” may block the installer

SonarDepthPro is not yet code-signed with a commercial certificate. On Windows 11 machines where Smart App Control is active, Windows may refuse to start the program. This is not a fault in the program or in your sonar files — Windows is blocking any application it does not yet recognise.

To allow SonarDepthPro to run:

  1. Open Windows Security
  2. Go to App & browser control
  3. Open Smart App Control settings
  4. Set Smart App Control to Off
  5. Run the installer again

Most computers already have Smart App Control switched off, in which case you will never see this message. If the setting is not shown at all, it is not active on your machine and something else is the cause — please get in touch.

Note: on Windows 11 versions older than April 2026, turning Smart App Control off cannot be undone without reinstalling Windows. Update Windows first if you would like to be able to switch it back on later.

Do I need an internet connection to use SonarDepthPro?

No. You only need to be online once to activate your license key. After that, the software runs completely offline on your Windows machine. Your sonar data stays on your computer and is never uploaded anywhere.

Will SonarDepthPro always be able to read my recordings?

SonarDepthPro is built to read the .rsd files generated by current and past Garmin® units. However, because this is a proprietary file format, Garmin could technically change how they encode these files in a future firmware update.

If they do, I will do my best to figure out the changes and update SonarDepthPro. But since VisionFrame is completely independent and receives no technical specifications from the manufacturer, I cannot guarantee that future device updates won’t break compatibility. You are buying a tool that works with the files your equipment produces today.

Are updates included in the price?

Yes. Your one-time purchase includes all minor updates and bug fixes for the current major version. If Garmin makes small changes that I can patch, that update will be free. There are no subscriptions and no hidden fees.

Why is SonarDepthPro a paid tool rather than free open source?

While SonarDepthPro builds upon public reverse-engineering research and open-source parsing techniques, turning raw data streams into a fast, stable desktop application with full visual rendering, measurement tools, and a clean interface takes hundreds of hours of specialized work.

Charging a fair, one-time price allows VisionFrame to remain independent:

  • Personal support: When you have a question or an issue, you get direct help from the developer who wrote the code.
  • Ongoing maintenance: It funds continuous bug fixes, performance improvements, and support for newer Windows updates.
  • No hidden catches: Because you pay upfront, the software doesn’t need to track you, show ads, force online accounts, or lock you into recurring subscriptions.

You are paying for a complete, maintained, and reliable tool—not just raw code.

Can I use this software to navigate?

Absolutely not. SonarDepthPro is designed exclusively for viewing and reviewing sonar data after you have safely returned to shore. It is not a navigation system, and the depth estimates on screen must never be used for hazard avoidance.
